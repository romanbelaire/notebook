# PDF Renderer

The `gfx/pdf_renderer.rs` module provides PDF rendering functionality.

## Overview

The PDF renderer:
- Loads PDF files
- Renders PDF pages to textures
- Displays PDFs in the UI

## PDF Rendering

PDFs are rendered to textures and displayed in the PDF modal.
