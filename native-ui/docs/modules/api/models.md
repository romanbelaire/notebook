# API Models

The `api/models.rs` module defines API data structures.

## Chat Models

- `ChatRequest`: Chat request payload
- `ChatResponse`: Chat response
- `ApiChatMessage`: Chat message format

## Collection Models

- `Collection`: Collection data structure

## Paper Models

- `ApiPaper`: Paper data structure

## Insight Models

- `Insight`: Insight data structure
- `CreateInsightRequest`: Create insight request
- `UpdateInsightRequest`: Update insight request
