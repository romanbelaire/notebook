# Conversation Persistence

The `persistence/conversation.rs` module handles conversation persistence.

## Methods

- `save_conversation()`: Save conversation to disk
- `load_conversation()`: Load conversation from disk
- `list_conversations()`: List all conversations

## Storage

Conversations are stored as JSON files in `data/conversations/`.
