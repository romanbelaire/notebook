# Stylus Module

The `stylus/` module provides the rich text editor system.

## Module Structure

```
stylus/
├── editor.rs      # Text editor
├── document.rs    # Document model
├── block.rs       # Text blocks
├── cursor.rs      # Cursor management
├── formatting.rs  # Text formatting
└── renderer.rs    # Rendering
```

## Stylus Editor

The Stylus editor provides:
- Multi-block text editing
- Markdown support
- Rich formatting
- Cursor and selection
